NeoCalc: UI Modernization, Variable Support, and Code Cleanup

This release represents a significant overhaul of the user interface and internal structure of NeoCalc. 
The primary focus was on achieving GNOME Human Interface Guidelines (HIG) compliance, optimizing the window layout 
for compact sizes, and implementing a robust "Variables" feature backed by the Rust engine.

UI Modernization & Layout:
The window sizing logic has been completely rewritten. We replaced `Adw.ViewStack` with `Gtk.Stack` to allow 
independent width sizing for different modes, solving the issue where "Scientific" mode forced "Standard" mode 
to be unnaturally wide. Button sizes were refined to a natural 42px minimum with `Gtk.Align.FILL` to eliminate 
empty space. Typography was updated to use tabular figures (`tnum`) in `Adwaita Mono`, preventing jitter during 
calculation. The header bar was simplified by merging the mode switcher into a compact split button.

Functional Enhancements:
A new "Variables" feature has been implemented. Users can now view defined variables (e.g., `x = 10`) via a 
dedicated dialog and insert them into calculations. This leverages the existing Rust backend capabilities which 
were previously unexposed.

Versioning & Maintenance:
We introduced Git-based dynamic versioning (`vYEAR.MONTH-REVISION`), ensuring the "About" dialog always reflects 
the exact commit tag. Stale code, including unused test scripts (`test_layout.py`) and legacy imports 
(`concurrent.futures`), was analyzed and removed.
